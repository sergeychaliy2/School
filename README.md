# Расписание Новоселицкой СОШ

Мобильное приложение с расписанием уроков МАОУ «Новоселицкая СОШ» — 1–10 классы,
офлайн, с подсветкой текущего урока и обратным отсчётом до звонка.

Expo (React Native) + TypeScript. Цель сборки — Google Play.

## Откуда берутся данные

Это главное, что нужно понимать про проект.

Школа публикует расписание **только сканами PDF** — два файла на
[странице расписания](https://sh-novoselickaya-r49.gosweb.gosuslugi.ru/glavnoe/raspisanie/).
Встроенный на сайте модуль расписания пустой («Расписание на этот год не
заполнено»), а сами PDF — картинки без текстового слоя. Поэтому **распарсить
сайт, как это делается для обычных сайтов, нельзя**: парсить там нечего.

Что сделано вместо этого:

| Данные | Источник | Как обновить |
| --- | --- | --- |
| Расписание уроков | Сканы PDF, перенесены вручную | `tools/build_schedule.py` |
| Расписание звонков | Объявление на стене школы | `src/domain/bells.ts` |
| Контакты школы | Сайт школы | `src/data/school.ts` |

Приложение при этом умеет **замечать**, что сканы на сайте поменялись: экран
«Школа» → «Проверить обновления» шлёт HEAD-запрос и сравнивает `ETag` и
`Last-Modified` с теми, что записаны в `data/schedule.json`. Если файл на сайте
новее — приложение честно говорит об этом и отправляет на официальную страницу,
а не делает вид, что всё актуально.

> На момент сборки на сайте висит расписание, утверждённое 01.09.2025
> (файлы менялись 21.12.2025). Расписание на 2026/27 школа ещё не выкладывала.

## Запуск

```bash
npm install
npm start
```

Дальше — приложение **Expo Go** на телефоне: отсканировать QR из терминала.
Все нативные модули проекта входят в Expo Go, отдельная сборка для разработки не
нужна.

По кабелю (нужна отладка по USB на телефоне):

```bash
npm run android
```

## Проверки

```bash
npm run typecheck
npm test
```

`npm test` гоняет логику звонков и «что сейчас идёт» — границы уроков и перемен,
выходные, дни без уроков, приёмы пищи по классам.

## Обновить расписание, когда школа выложит новое

1. Скачать свежие сканы со страницы расписания.
2. Поправить таблицы в `tools/build_schedule.py` — они лежат там в компактном
   виде `"Предмет|Кабинет"`, по строке на урок.
3. Обновить `etag` / `lastModified` / `bytes` в блоке `sources`
   (`curl -I <url>` покажет их).
4. Пересобрать данные:

```bash
npm run schedule
```

Скрипт перезапишет `data/schedule.json` и скопирует его в `src/data/`, а в конце
напечатает количество уроков по классам — удобно сверить со сканом.

## Сборка для Google Play

```bash
npm install -g eas-cli
eas login
eas build --platform android --profile production
```

Профиль `production` собирает `.aab` для Play. Перед первой публикацией:

- **Package name** уже задан: `ru.novoselicy.schedule` (`app.json`).
- **Политика конфиденциальности** — [PRIVACY.md](PRIVACY.md), её нужно выложить
  по публичному URL и указать в Play Console.
- **Data safety** в Play Console: приложение не собирает и не передаёт данные —
  имя и класс не покидают устройство, разрешений нет.
- **Целевая аудитория**: если указать возраст до 13 лет, подключится
  Families Policy с дополнительными требованиями. Приложение под неё
  технически подходит (нет рекламы, аналитики и сбора данных), но проверка
  листинга будет строже.

## Структура

```
data/schedule.json        единый источник правды по расписанию
tools/build_schedule.py   генератор этого файла из читаемых таблиц
tools/domain.test.ts      проверки логики звонков
tools/make_icons.py       генератор иконок и сплэша

src/
  app/                    экраны (expo-router)
    (tabs)/               Сегодня · Неделя · Школа
    welcome.tsx           выбор класса и имени
    settings.tsx          профиль, тема
    bells.tsx             редактор звонков
  domain/                 чистая логика без React — здесь считается «что сейчас»
  store/app.tsx           локальный профиль и настройки (AsyncStorage)
  components/             переиспользуемый UI
  theme/                  токены дизайна, светлая и тёмная тема
```

Слой `domain/` намеренно не знает про React: поэтому его можно проверять обычным
`node`, что `npm test` и делает.

## Приватность

Профиль (имя и класс) хранится только на устройстве. Приложение не запрашивает
разрешений, не содержит аналитики и рекламы и работает без интернета.
Подробнее — [PRIVACY.md](PRIVACY.md).
