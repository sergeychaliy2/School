# Политика конфиденциальности

**Приложение:** Расписание Новоселицкой СОШ
**Обновлено:** 25 сентября 2026 г.

## Коротко

Приложение не собирает персональные данные, не передаёт их никуда и не требует
регистрации. Всё, что вы вводите, остаётся на вашем устройстве.

## Какие данные вводит пользователь

При первом запуске можно указать:

- **класс** — обязательно, чтобы показать нужное расписание;
- **имя** — необязательно, только для приветствия на главном экране.

Эти данные сохраняются **исключительно в памяти вашего устройства** (локальное
хранилище приложения). Они не отправляются на серверы, не передаются третьим
лицам, не используются для аналитики и недоступны разработчику.

Удалить их можно в любой момент: «Настройки» → «Выйти из профиля», либо удалив
приложение — вместе с ним стирается всё, что оно хранило.

## Обращения к сети

Приложение работает полностью офлайн. Сеть используется только в двух случаях, и
оба запускаются вручную самим пользователем:

1. **«Проверить обновления»** — приложение отправляет HEAD-запрос к файлам
   расписания на официальном сайте школы, чтобы сравнить дату их изменения.
   Никакие данные пользователя в запросе не передаются.
2. **Переход по ссылке** (сайт школы, электронный дневник и т. п.) — открывается
   браузер, дальше действуют правила соответствующего сайта.

## Чего приложение не делает

- Не запрашивает разрешений (камера, геолокация, контакты, файлы, уведомления).
- Не использует рекламу, трекеры и системы аналитики.
- Не создаёт учётных записей и не хранит паролей.
- Не собирает идентификаторы устройства.

## Дети

Приложение предназначено для учеников школы. Поскольку никакие данные не
покидают устройство и не попадают к разработчику или третьим лицам, обработка
персональных данных в смысле Федерального закона № 152-ФЗ не производится.
